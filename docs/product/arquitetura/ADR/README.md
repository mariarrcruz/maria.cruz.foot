# Architecture Decision Records

ADRs da arquitetura do PDV da Carla.

## Escopo

Estes registros documentam decisões arquiteturais propostas para avaliação. Eles não alteram a fonte de verdade em `docs/product/arquitetura/arquitetura.md`, nos RFCs ou nas personas.

## Status

- **Proposta:** recomendação ainda não aprovada.
- **Bloqueada:** não pode ser fechada enquanto uma lacuna de requisito permanecer.
- **Condicional:** só se aplica caso uma extensão seja aprovada.

## Convenção

Cada ADR contém contexto, forças, alternativas, decisão, consequências, riscos e requisitos relacionados. Valores M-04 a M-08 permanecem hipóteses provisórias e não devem ser tratados como fatos.
